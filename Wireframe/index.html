What is the purpose of README?

Is a file that explains what your projects is about,why you created it and how people can use it.

What is the purpose of a wireframe?

Is a simple visual sketch of how a website or app will look before you start coding.

What is a branch in Git?

A branch in Git is a separate version of your project where you can make changes or test new features without affecting the main version.
